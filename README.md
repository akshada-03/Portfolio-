# 🌟 Personal Developer Portfolio — Akshada Hadal

An ultra-modern, fully responsive, and dynamic personal developer portfolio website designed to showcase **Full-Stack & Web Development** projects, technical skills, certifications, and career journey. Built using **Vanilla HTML5, CSS3, Tailwind CSS**, and modern **ES6+ JavaScript**.

---

## ✨ Features

- 🎨 **Modern Design System**: Sleek dark/light theme, glassmorphism navbar, and subtle micro-animations.
- 🌙 **Theme Toggle**: Dark and Light mode toggle with persistent state via `localStorage`.
- ⚡ **Typewriter Animation**: Dynamic hero section typewriter effect cycling through developer roles.
- 📜 **Scroll Reveal & Progress Bars**: Intersection Observer API driving smooth scroll reveal animations and skill bars.
- 🔍 **Interactive Project Filters**: Categorized tabs (`All Projects`, `PHP / Laravel`, `Full Stack`, `Frontend`) with smooth CSS fade transitions.
- 💼 **Project Detail Modals**: Modal dialogs displaying in-depth technical breakdowns (architecture, ER diagrams, AI service layers, and test suites) for featured projects.
- 📩 **Working Contact Form**: Integrated AJAX email delivery forwarding visitor messages directly to Gmail inbox.
- 📱 **Fully Responsive**: Mobile-first responsive design tested on desktop, tablet, and mobile viewports.

## ⚡ Quick Start & Local Development

No complex build tools or bundlers required! Simply clone and serve locally.

### 1. Clone the Repository
```bash
git clone https://github.com/akshada-03/Portfolio-.git
cd Portfolio-
```

### 2. Run Locally
Open `index.html` directly in your browser, or serve using any local HTTP server:

```bash
# Using Node npx serve
npx serve .

# Or open directly in browser on Windows
start index.html
```
